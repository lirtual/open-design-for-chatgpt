# Prototype template index

Select one starter as a **resource**, not as a different Skill. Read its source only when selected; adapt names, tokens and layout. All starters are self-contained local HTML/CSS/JS without external requests.

| Request | Starter | Extra check |
| --- | --- | --- |
| General webpage, docs or feature page | [web-prototype](../assets/web-prototype.html) | 375, 768 and 1440 viewport widths |
| Product marketing/price page | [saas-landing](../assets/saas-landing.html) | Pricing is illustrative unless verified |
| Analytical/operations dashboard | [dashboard](../assets/dashboard.html) | Label demonstration metrics, cover data states |
| Responsive mobile app UI | [mobile-app](../assets/mobile-app.html) | Do not imply native iOS/Android compilation |
| Early structural wireframe | [wireframe-greybox](../assets/wireframe-greybox.html) | Structure first; intentionally suppress brand decoration |

For website cloning: read only source and assets the host actually has permission to access, respect copyright and authentication boundaries; screenshots are not real DOM measurements. Do not copy an entire site merely because a URL is provided.
