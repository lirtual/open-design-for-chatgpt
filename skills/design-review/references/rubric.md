# Review rubric

- **Hierarchy:** can the first-time user identify the primary task, CTA and next step without scanning unrelated cards?
- **Contrast:** use an actual color-ratio calculation before claiming WCAG AA; typical normal text target 4.5:1 and UI components 3:1; use applicable exceptions carefully.
- **Keyboard:** visible focus, logical reading/tab order, labels and error association; only verify behavior in rendered browser.
- **Touch:** comfortable controls and adequate spacing on mobile; do not equate screenshot size to actual CSS pixels.
- **States:** loading, empty, error, populated and edge behavior; validate fields and pending submission.
- **Responsive:** phone, tablet, desktop layout, overflow, long words, RTL where relevant.
- **Security/privacy:** no surprise data exfiltration or third-party scripts introduced by suggested improvements.

Report each finding as `Priority / location / observed evidence / impact / smallest fix / verification`.
